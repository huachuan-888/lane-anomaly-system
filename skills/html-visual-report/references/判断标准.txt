清晰度综合评分公式：
S = w1 * L + w2 * E + w3 * C + w4 * B + w5 * F
其中：S为综合评分，L为Laplacian方差，E为边缘密度，C为对比度，B为Brenner梯度，F为FFT能量，w1-w5为各指标权重。
异常检测规则：
规则一：车道线缺失检测
判断条件：id=1（本车道左侧）或id=-1（本车道右侧）不在检测到的车道线ID列表中，则判定为车道线缺失。
规则二：异常抖动检测
判断条件：|C0(t) - C0(t-1)| >= 0.2，连续3帧满足条件记为一次抖动事件。其中C0为车道线曲率参数。
规则三：宽度异常检测
判断条件：总宽度=|C0左| + |C0右|，当总宽度<=3.4时判定为过窄，当总宽度>=4.0时判定为过宽。
