# 车道线异常智能归因系统

基于 D760 王者6x4 自主一代 L2+ 智驾项目的车道线异常自动化分析平台。

## 功能

- 问题列表驱动全自动分析（从测试问题表 xlsx 出发）
- 关键字提取：自动筛选车道线/压线/蛇形相关问题
- CSV 数值异常检测：缺失 / 抖动 / 宽度异常（双阈值 4.0m/4.1m）/ 可视范围
- 视频抽帧：精准提取故障时刻画面（b1±1s 三张）
- 清晰度评估：S = w1·L + w2·E + w3·C + w4·B + w5·F（支持自定义权重）
- 场景识别：隧道 / 弯道 / 昼夜 / 天气
- 双维度校验：CSV 异常 vs 画面实际车道线检测（Hough），自动归因
- 可视化 HTML 报告：统计指标 + 异常趋势 + 错误点截图

## 文件结构

```
车道线异常智能归因系统/
├── app.py               Flask Web 系统 (http://localhost:5000)
├── templates/           网页模板
├── 启动系统.bat          一键启动脚本
└── 车道线自动复核.py      命令行批量复核流水线
```

## 启动

```powershell
cd 车道线异常智能归因系统
python app.py
# 浏览器打开 http://127.0.0.1:5000/
```

或双击 `启动系统.bat`（自动打开浏览器）。

## 依赖

- Python 3.8+
- openpyxl, flask
- opencv-python, numpy

## 技术要点

- TS 视频必须顺序读帧（cap.set() 对 TS 跳帧不可靠）
- 视频开头约 3 帧缓冲，帧号需 +3 补偿
- 双维度校验用 Hough 检测画面实际车道线宽度，与 CSV 上报宽度对比归因
