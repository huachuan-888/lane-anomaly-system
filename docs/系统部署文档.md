# 车道线异常智能归因系统 · 部署交付文档

**版本**：V1.0 正式版
**适用范围**：Windows 10/11 电脑
**部署方式**：A. 桌面版 exe（免安装）/ B. Python 脚本 / C. Hermes AI 技能
**文档日期**：2026年8月

---

## 文档说明

本文档用于将《车道线异常智能归因系统》部署到其他电脑。系统提供三种部署形态，按目标电脑的使用者情况选择：

| 形态 | 目标使用者 | 前置要求 | 特点 |
|------|-----------|---------|------|
| A. 桌面版 exe | 导师/同事（不搞技术）| 无 | 双击即用，最省心 |
| B. Python 脚本 | 会 Python 的工程师 | 装 Python + 依赖 | 灵活可改 |
| C. Hermes 技能 | 配合 AI 使用 | 装 Hermes | 对话式自动化 |

> ⚠️ **三种形态共用同一套数据**：问题表 xlsx + 车道线 CSV + 行车视频。数据目录结构见下文「数据准备」。

---

# 数据准备（三种方法共用）

无论用哪种方法部署，目标电脑都需要准备数据目录：

```
数据\
├── V1.1.6版本测试问题.xlsx          ← 测试问题表（必须有！）
├── 同类型CSV_lane_mark_camera_list_1\  ← 车道线感知CSV（106个）
└── 视频\                            ← 行车视频
    ├── 6.16\                        ← 按日期子目录（可选结构）
    ├── 6.17\
    └── 6.18\
```

**说明**：
- 视频按日期子目录存放（`6.16/6.17/6.18`）为推荐结构；也可以任意平铺，系统会自动递归查找
- 视频可以裁剪（只带需要的时段），CSV 建议全带
- 系统**自动检测数据目录**，不依赖固定路径

# 方法 A：桌面版 exe 部署（推荐）

## A1. 获取安装包

从开发机获取（或从发布渠道下载）`车道线归因系统` 文件夹：

```
车道线归因系统\
├── 车道线归因系统.exe   ← 主程序（51.6MB）
└── _internal\           ← 运行库（必须与exe一起拷贝！）
```

**传输方式**（任选）：
- 微信/QQ 文件传输（先压缩成 zip）
- 网盘（百度网盘/阿里云盘）
- U盘/移动硬盘拷贝

**压缩建议**：整个文件夹约 746MB，压缩后约 250~300MB。

## A2. 安装部署（目标电脑）

**第 1 步**：解压 `车道线归因系统.zip` 到任意位置（如 `D:\` 或桌面）

**第 2 步**：在解压后的文件夹内新建 `数据` 子目录，放入数据：

```
车道线归因系统\
├── 车道线归因系统.exe
├── _internal\
└── 数据\
    ├── V1.1.6版本测试问题.xlsx
    ├── 同类型CSV_lane_mark_camera_list_1\
    └── 视频\
```

**第 3 步**：双击 `车道线归因系统.exe` 启动

**第 4 步**：约 2 秒后浏览器自动打开 `http://127.0.0.1:5000/`，进入系统首页

## A3. 使用说明

| 功能 | 操作 |
|------|------|
| 查看问题列表 | 首页自动展示 33 个问题（含归类/场景/时间）|
| 问题详情分析 | 点击问题 → 错误点 + 截图 + 双维度校验 |
| 翻页 | 页面左右两侧的 ⬅ ➡ 悬浮按钮 |
| 展开全部错误点 | 点击「展开全部 N 个错误点」按钮 |
| 停止服务 | 关闭 cmd 窗口（即停止）|

**注意**：
- `exe` 和 `_internal` 必须放在同一文件夹，不能只拷 exe
- 关闭黑色 cmd 窗口 = 停止服务
- 若浏览器未自动打开，手动访问 `http://127.0.0.1:5000/`

## A4. 验证安装

启动后首页应显示：
- 统计卡：问题总数 33 / 车道线问题 / 蛇形问题
- 问题列表带场景标签（隧道/弯道/分合流/天气）

点击任意问题，详情页应显示：
- 错误点列表（时间/类型/截图）
- 双维度校验结论（真实异常/疑似误报/需复核）

# 方法 B：Python 脚本部署

## B1. 前置环境（目标电脑）

**第 1 步**：安装 Python 3.9 或更高版本
- 下载：https://www.python.org/downloads/
- 安装时勾选 **Add Python to PATH**（重要！）

**第 2 步**：验证安装

```bash
python --version
# 应显示 Python 3.9.x 或更高
```

## B2. 获取代码

方式一：从 GitHub 克隆（推荐）

```bash
git clone https://github.com/huachuan-888/lane-anomaly-system.git
```

方式二：直接拷贝（U盘/网盘）

```
lane-anomaly-system\
├── 车道线自动复核.py              ← 主流水线
├── app.py                         ← Web 系统
├── templates\                     ← 网页模板
├── 车道线分析工具\
│   ├── analyze_pipeline.py        ← 单CSV分析
│   └── index.html
├── 启动系统.bat
└── models\
    └── yolop-640-640.onnx         ← YOLOP模型（34MB，可在线下载）
```

## B3. 安装依赖

```bash
pip install opencv-python numpy openpyxl flask onnxruntime matplotlib
```

> 模型 yolop-640-640.onnx 可从 GitHub Release 下载：
> `https://github.com/huachuan-888/lane-anomaly-system/releases/download/v1.0-models/yolop-640-640.onnx`
> 放到 `models\` 目录

## B4. 使用方式

### 方式 1：命令行全量复核（生成报告）

```bash
cd 数据目录          # 进入含 xlsx+CSV+视频 的目录
python 车道线自动复核.py
```

输出：`自动复核输出\reports\错误点复核报告.html`（浏览器打开）

### 方式 2：单 CSV 快速分析

```bash
cd 数据目录
python 车道线分析工具\analyze_pipeline.py
```

自动检测当前目录 CSV + 匹配视频，输出 HTML+MD 报告。

### 方式 3：Web 界面

```bash
cd 车道线异常智能归因系统
python app.py
# 或双击 启动系统.bat
# 浏览器打开 http://127.0.0.1:5000/
```

## B5. 验证安装

```bash
python -c "import cv2, openpyxl, flask; print('依赖 OK')"
```

## B6. 常见问题

| 问题 | 解决 |
|------|------|
| `pip` 不是内部命令 | Python 未加入 PATH，重装并勾选 |
| 找不到 CSV | 确认 CSV 在**当前目录**或子目录（自动递归查找）|
| 无视频帧 | 该时段视频未录制（数据特性）；确认视频文件名含时间戳 `ND02512_HHMMSS_vedio` |
| 中文乱码 | 用 Python 运行（勿用 PowerShell 重定向写文件）|

# 方法 C：Hermes AI 技能部署

## C1. 前置环境（目标电脑）

安装 Hermes Agent（官方开源 AI Agent 框架）

```bash
# Windows 安装（PowerShell）
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
# 或 pip 安装
pip install hermes-agent
```

**初始化**：

```bash
hermes setup        # 配置模型/提供商
hermes              # 启动交互式对话
```

## C2. 安装技能

方式一：从 GitHub 拉取（推荐）

```bash
git clone https://github.com/huachuan-888/lane-anomaly-system.git
# 将 skills/html-visual-report 复制到 Hermes 技能目录
copy lane-anomaly-system\skills\html-visual-report <hermes-home>\skills\
```

方式二：直接拷贝技能文件夹

```
html-visual-report\
├── SKILL.md                    ← 技能说明书
├── scripts\
│   ├── generate_report.py      ← 入口
│   ├── reference_engine.py     ← 分析引擎
│   └── setup_env.py            ← 环境自动配置
├── references\                 ← 判断标准/时间对齐经验
└── assets\                     ← 报告样式
```

## C3. 使用方式

启动 Hermes 后，直接对话：

```
"分析车道线数据，生成报告"
"用数据与工具目录的数据出报告"
```

Hermes 自动：
1. 加载 html-visual-report 技能
2. 自动检测数据目录（当前文件夹/指定路径）
3. 运行完整分析流程（问题表驱动 → 规则检测 → 视频抽帧 → 双维度校验）
4. 生成深色 HTML 报告

**首次使用**：技能脚本会自动检测依赖并提示安装（cv2/onnxruntime 等），按提示操作即可。

## C4. 验证

```bash
hermes skills list
# 应显示 html-visual-report
```

# 附录：三种方法对比与选择

| 对比项 | A. exe | B. Python | C. Hermes |
|--------|:---:|:---:|:---:|
| 安装难度 | ⭐ 无 | ⭐⭐⭐ 装环境 | ⭐⭐⭐⭐ 装Hermes |
| 传输大小 | 746MB | ~100KB+依赖 | 156KB |
| 目标电脑要求 | 无 | Python+依赖 | Hermes+API密钥 |
| 使用门槛 | 双击 | 命令行 | 对话 |
| 修改定制 | 不可 | 可改代码 | 可改技能 |
| 推荐使用者 | 导师/同事 | 工程师 | AI用户 |

**选择建议**：
- 给**导师演示** → 方法 A（exe，最省事）
- 给**会编程的同事** → 方法 B（脚本，可扩展）
- 给**自己多台电脑** → 方法 C（技能，从 GitHub 随时拉）
